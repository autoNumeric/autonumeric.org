## Questions and support

For questions and support, join the [Gitter chat room](https://gitter.im/autoNumeric/autoNumeric).

## Bugs and feature requests

If you found a problem with AutoNumeric or have an idea to improve it, [open an issue on GitHub](https://github.com/autoNumeric/autoNumeric/issues/new) and we'll take a look.

::: info
The issue list is **exclusively** for bug reports and feature requests.
:::

## Contributing

If you already feel comfortable with the AutoNumeric source code, you can directly [create a pull request](https://github.com/autoNumeric/autoNumeric/compare): contributions are very welcome! Please read the [contributing guidelines](https://github.com/autoNumeric/autoNumeric/blob/next/doc/CONTRIBUTING.md) first.
