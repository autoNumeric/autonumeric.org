# Installation

You can install AutoNumeric with your preferred dependency manager:

**Latest version**

::: code-group
```sh [With yarn]
yarn add autonumeric
```
:::
::: code-group
```sh [With npm]
npm install autonumeric --save
```
:::

**Stable version**

::: code-group
```sh [With yarn]
yarn add autonumeric@4.10.10
```
:::
::: code-group
```sh [With npm]
npm install autonumeric@4.10.10 --save
```
:::


- [Yarn](https://yarnpkg.com/) website
- [NPM](https://www.npmjs.com/) website
