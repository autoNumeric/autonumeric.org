Choose a value for each option you want to change: the options object is generated as you go, and the input on the right uses it immediately. Options left on their default value are not included.

The object can be generated in its **simplified** form, with the values themselves, or in its **detailed** form, which refers to the `AutoNumeric.options` constants.
